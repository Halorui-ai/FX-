# KPI 看板卡片重设计 · 实现说明书（HANDOFF）

配套高保真原型：`index.html`（自包含、零依赖，浏览器直接打开；大卡右上角 Tab 可点击切换）。
请先在浏览器打开原型确认视觉与交互，再按本说明书实现为项目组件。

---

## 1. 背景与目标

数据看板上的 KPI 卡片可拖拽调整大小，共三种形态，信息密度递进：

| 形态 | 定位 | 本次改动 |
|---|---|---|
| 小卡 S | 标题 + 单个核心数字 | **保持现状不动** |
| 中卡 M | 核心数字 + 构成微图表 + 3 个细分指标 | 重新设计（见 §3） |
| 大卡 L | 详情页摘要：核心指标 + 维度环图 + 最新记录表 | 重新设计（见 §4） |

设计原则：

1. 每张卡只有一个视觉焦点（主数字），其余指标退居次级层级；
2. 中卡/大卡使用统一外壳（拖拽柄 + 语义色条 + 图标 + 标题 + 关闭按钮），与现有小卡一致；
3. 颜色只出现在数字、状态点、图表、标签上，卡片本体始终是中性毛玻璃面；
4. 大卡 = 二级详情页的摘要，右栏列表承担「下钻入口」，点击进现有详情页。

共 4 个指标卡：**放行单总数、特级安保单、在途超时未放行、超时未接收**。

## 2. 通用设计 Token

直接取自原型 `:root`，实现时抽成全局 CSS 变量 / Design Token。

### 2.1 语义色

| Token | 色值（亮色） | 含义 |
|---|---|---|
| `--brand` | `#2f7cf6` 蓝 | 总量 / 普通单 / 主色 |
| `--cat-purple` | `#7a63f5` 紫 | 特级安保单 |
| `--warn` | `#f59a26` 橙 | 超时预警（在途超时） |
| `--danger` | `#f04d3e` 红 | 告警（超时未接收、門崗異常） |
| `--cyan` | `#15b3c4` 青 | 辅助强调（记录数） |
| `--ok` | `#1ea672` 绿 | 正常 / 已核验 |

对应 soft 底色（徽章/标签用，透明度混合即可）：
`--brand-soft rgba(47,124,246,.1)`、`--danger-soft rgba(240,77,62,.12)`、
`--warn-soft rgba(245,154,38,.12)`、`--ok-soft rgba(30,166,114,.12)`、`--purple-soft rgba(122,99,245,.1)`。

### 2.2 中性色 / 面

| Token | 值 | 用途 |
|---|---|---|
| `--card` | `rgba(255,255,255,.74)` | 卡片底色（毛玻璃） |
| `--card-strong` | `rgba(255,255,255,.9)` | 选中态/hover 面 |
| `--panel` | `rgba(255,255,255,.56)` | 卡内嵌套面板（大卡右栏、Tab 容器） |
| `--line` | `rgba(31,41,55,.09)` | 分隔线、描边 |
| `--track` | `rgba(31,41,55,.08)` | 进度条/环图轨道 |
| `--text` `--muted` `--faint` | `#20262e` `#748093` `#9aa5b5` | 主/次/弱文本 |

卡片毛玻璃：`backdrop-filter: blur(18px)`；
阴影：`0 10px 30px rgba(28,45,74,.08), inset 0 1px 0 rgba(255,255,255,.5)`。

### 2.3 圆角 / 间距 / 字体

- 圆角：卡片 `16px`，控件/标签 `8px`，胶囊/圆点 `999px`
- 间距阶梯：4 / 8 / 12 / 16 / 20 / 24
- 字体：正文 `"PingFang SC","Microsoft YaHei",system-ui`；数字使用 Inter 或同族并加 `font-variant-numeric: tabular-nums`；单号用等宽字体（JetBrains Mono / SF Mono / Consolas）
- 字号：卡片标题 15/22；中卡主数字 38；大卡主数字 52；指标值 18；正文 13~14；辅助文字 12；标签 11

> 暗色模式：原型 `:root` 注释中给了参考覆写值，如项目需要请按同一组 Token 覆写。

## 3. 中卡规格（Medium）

### 3.1 统一结构（三段式）

```
┌ 表头：拖拽柄 │ 4px 语义色条 │ 图标 │ 标题            × ┐
├ 主信息区（左右分栏）                                     │
│   左：主数字(38px) + 单位        右：构成微图形(104px)   │
│       副说明(12px)                                       │
├ 底部指标条：3 等分列，竖线分隔，状态点 + 标签(12) + 值(18) │
└──────────────────────────────────────────────────────────┘
```

- 整张卡一个语义色（头部色条/图标/主数字/微图形同色），通过修饰类切换：
  `v-brand` / `v-purple` / `v-warn` / `v-danger`
- 底部 `.cell` 之间用 1px 竖线分隔；数字颜色可用 `--dc` 单独指定（如特保紫、超时橙）

### 3.2 四张中卡的内容与数据字段

**① 放行单总数（蓝 v-brand，主数字保持深色不用蓝色）**
- 主数字：`totalOrders`（202，单位"单"）；副说明：放行记录 `totalRecords`（393）条
- 右侧：双扇区迷你环图，中心文字 = 特保占比 `specialRatio`（16.8%）+ "特保占比"
- 底部分列：特保 `specialOrders`(34, 紫) / 普通 `normalOrders`(168) / 在途 `inTransitOrders`(76, 橙)

**② 特级安保单（紫 v-purple）**
- 主数字：`specialOrders`（34，单）；副说明：占放行单总数 `specialRatio`（16.8%，紫色）
- 右侧：单值环形进度（进度 = specialRatio），中心 = 特保记录数 `specialRecords`（70）+ "特保记录"
- 底部分列：特保记录 `specialRecords`(70 条) / 占总单 `specialRatio`(16.8%) / 普通单对照 `normalOrders`(168, 弱化色)

**③ 在途超时未放行（橙 v-warn）**
- 主数字：`overtimeNotReleased`（40，单）；副说明：在途单据共 `inTransitOrders`（76）单
- 右侧：100% 水平堆叠条（两段：超时 `overtimeNotReleased` 橙色 flex:40；未超 `inTransitNormal`(36) 蓝色 flex:36），下方两行图例
- 底部分列：其中特保 `overtimeSpecial`(8, 紫) / 在途未超 `inTransitNormal`(36) / 占在途 `overtimeInTransitRatio`（40/76=52.6%，橙）

**④ 超时未接收（红 v-danger）**
- 主数字：`overtimeNotReceived`（14，单）；副说明：固定文案"需及时跟进接收"
- 右侧：告警徽章（84px 圆角方块，danger-soft 底 + 时钟图标），不硬塞图表
- 底部不放指标列，改为整宽文字按钮「查看超时单据明细 →」（红色文字、顶部分隔线、hover 箭头右移 3px），点击跳转/打开该指标的过滤明细页

### 3.3 中卡尺寸建议

- 建议栅格占位：宽 ≥ 2 列、高约 200~220px；两列一行排列（原型 720px 以下降为单列）
- 内容超出宽度时：底部指标条允许标签省略号，不允许缩字号

## 4. 大卡规格（Large）

### 4.1 整体布局

表头同中卡，标题右侧放置**维度切换胶囊 Tab**（分段控件，三段：单据类型 / 到达状态 / 超时状态），再右侧是关闭按钮。

内容区为三栏 Grid（原型列宽 `238px / 290px / 1fr`，栏间距 24）：

```
┌ 左栏 238 ──┬── 中栏 290 ──┬── 右栏 自适应 ──┐
│ 主数字 52  │              │ 最新放行记录     │
│ 副说明     │   环形图     │ ┌─────────────┐ │
│ ─────────  │   中心总数   │ │ 明细表格 4 行 │ │
│ 指标行 ×3  │   引导线标签 │ │              │ │
│ (名称+值+  │              │ 全部 393 条 →   │
│  占比条)   │ 图例胶囊 ×2  │ 点击查看完整明细 │
└────────────┴──────────────┴─────────────────┘
```

中栏左右各一条竖向分隔线。1100px 以下三栏堆叠为单列（中栏改为横向分隔线）。

### 4.2 左栏：核心指标

- 主数字 `totalOrders`（202，52px）+ 单位"单"；副说明"放行记录 393 条 · 实时更新"
- 下方 3 行指标，每行 = 名称（带状态点）+ 右侧数值 + 5px 占比进度条：
  - 特级安保单 34，16.8%，紫条
  - 普通单 168，83.2%，蓝条
  - 在途单据 76，37.6%，橙条（占比基数为总单数 202）

### 4.3 中栏：维度环图（随 Tab 切换）

- 环图：半径 86、描边 27、轨道色 `--track`，两扇区间留 7 单位间隙，从 12 点钟方向起绘
- 中心：总数（30px 粗体）+ "总单数"
- 两个扇区各带一条引导线 + 两行标签（名称、"N 单 (xx.xx%)"）
- 下方两个图例胶囊：状态点 + 名称 + 粗体数值
- Tab 切换时扇区长度、颜色、引导线标签、图例全部数据驱动更新（过渡动画 300~400ms）

三个维度的数据（两个分类之和恒等于总数 202）：

| Tab | 小扇区 | 大扇区 |
|---|---|---|
| 单据类型 | 特级安保单 34（16.83%，紫） | 普通单 168（83.17%，蓝） |
| 到达状态 | 在途 76（37.62%，橙） | 已到达 126（62.38%，蓝） |
| 超时状态 | 超时未放行 40（19.80%，红） | 正常 162（80.20%，蓝） |

> 上表中的 126 / 162 为根据现有截图数值（76、40）按总数 202 守恒推算的演示数据，
> 实现时请替换为接口真实字段，不要写死。

### 4.4 右栏：最新记录表（下钻预览）

- 面板样式：`--panel` 底 + 1px 描边 + 16px 圆角
- 面板头：标题"最新放行记录" + 右侧链接"全部 {totalRecords} 条 →"
- 表格列（4 列，列宽 32% / 22% / 22% / 24%）：
  放行单号（等宽字体）｜ 申请时间（MM/DD HH:mm，弱化色）｜ 放行物品 ｜ 门岗核验（状态标签）
- 默认展示最新 4 条；行 hover 用 `--card-strong` 底；单元格超长省略号
- 状态标签两种：`門崗異常`（红 soft 底 + 红点，对应二级页流入门岗泛红的单据）、
  `已核驗`（绿 soft 底 + 绿点）
- 面板底部居中文案"点击查看完整明细页 →"，整块点击行为与现有卡片一致：打开现有二级详情页

数据字段（对齐二级页面表格）：
`orderNo`（放行单号）、`applyTime`（申请日期）、`applyDept`（申请部门，如需可替换"放行物品"列）、
`itemName`（放行物品名称）、`gateOut`（流出门岗）、`gateIn`（流入门岗）、
`gateActual`（实际放行门岗）、`gateAbnormal`（布尔，true 时显示門崗異常标签）。

### 4.5 其余三张大卡的内容映射（同一套三栏模板）

| 卡片 | 左栏主数字 + 进度条 | 中栏环图维度 | 右栏列表 |
|---|---|---|---|
| 特级安保单 | 34；特保记录 70 / 占比 16.8% / 涉及部门数（如接口有） | 特保单按状态/部门构成 | 最新特保记录列表（单号、时间、物品、安保等级标签） |
| 在途超时未放行 | 40；其中特保 8 / 在途未超 36 / 占在途 52.6% | 在途单：超时 vs 未超（橙/蓝）；可扩展超时时长分段 | 按超时时长降序的在途单（单号、流出门岗、超时时长、红色超时标签） |
| 超时未接收 | 14；可补充：平均超时时长、最长超时时长 | 超时未接收按时长分段（如 <1h / 1-4h / >4h，红系深浅） | 待接收列表（单号、流入门岗、应接收时间、超时时长），整卡主按钮"去处理" |

## 5. 交互要求

1. **拖拽缩放**：保持现有拖拽手柄与 resize 逻辑不变，仅替换卡片内容模板；尺寸跨越 S/M/L 断点时切换三种模板（S 沿用现状）。
2. **Tab 切换**（仅大卡）：分段控件选中项为白底胶囊 + 蓝字 + 轻阴影；环图数据过渡 300~400ms。
3. **悬停**：关闭按钮、表头链接、表格行、中卡④的 CTA 按钮按原型 hover 样式。
4. **点击下钻**：卡片主体 / "全部 N 条 →" / "查看完整明细页 →" 均打开现有二级详情页；中卡④直达「超时未接收」过滤视图；大卡 Tab 状态可带入详情页对应的 Tab（单据类型/到达状态/超时状态）。
5. 动效统一克制：位移 ≤ 3px、时长 ≤ 150ms（图表切换 ≤ 400ms）；尊重 `prefers-reduced-motion`。

## 6. 组件化建议

- 抽 3 个展示组件：`KpiCardShell`（表头外壳，传入 icon/title/color 语义色）、
  `MetricCardMedium`（传入配置：hero、visual 类型 donut|progress|stack|alert、cells[]）、
  `MetricCardLarge`（传入 hero、bars[]、dimensions{tabKey,segments[]}、records[]、detailUrl）
- 微图形建议：环图/堆叠条优先用 SVG 手绘（原型已给完整参数）；如项目图表库统一（ECharts 等），
  按同样的半径、描边宽度、间隙、配色复刻即可
- 所有数值、百分比、标签均由接口数据计算（百分比保留 1 位小数，环图引导线保留 2 位与二级页一致），原型中的数字仅为演示数据

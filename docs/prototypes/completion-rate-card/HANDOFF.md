## 1. 背景与目标

- **改什么卡**：`kpi_rate`（放行结案完成率），目前只有 S 小卡（水球图），补齐 M 中卡和 L 大卡形态
- **谁用、在哪种尺寸下看**：安保/物流管理人员在桌面看板上看；M 用于日常监控密度布局，L 用于下钻前的详情摘要
- **本次不改什么**：S 小卡水球形态保持不变；不改变结案率口径公式；不改动其他四张 KPI 卡

## 2. 设计 Token

与 `kpi-card-redesign/HANDOFF.md` §2 完全一致，复用现有语义色。本卡主色为绿色（正向达成率）。

| Token | 值（亮色） | 用途 |

## 3. 布局与分档

当前网格是 24 列 × 行高 48px（D-23）。KPI 换档条件见 ARCHITECTURE §4。

| 档 | 条件 | 卡内结构 |
|---|---|---|
| S | 小卡（默认 4×4） | 保持现状：标题 + 水球图 + 中心百分比，不动 |
| M | `h≥6` 或（`w≥10` 且 `h≥5`） | 左右分栏：左水球（约 120px） + 右三指标竖排（正常结案/到达超时/在途超时）；底部说明条 |
| L | `w≥12` 且 `h≥8` | 三栏布局：左栏大水球+图例 / 中栏 3 行进度条（正常/到达超时/在途超时）+ 底部纳入统计说明 / 右栏待关注单据列表；Tab 在卡片顶部居中；列表区 flex 填充，高度自适应可滚动 |

**中卡结构（M）**：

```
┌ 表头：拖拽柄 │ 绿色条 │ ✓图标 │ 放行结案完成率    × ┐
├ 主信息区（左右分栏）                                    │
│   左：水球图 SVG               右：正常结案  绿点 126 │
│      中心 61.4%                    到达超时  橙点  36 │
│      "放行结案完成率"              在途超时  红点  40 │
│                                  底部小字：纳入统计 202 单 │
├ 底部说明条（分隔线）                                    │
│   左：在途未超 76 单不计入分母     右：查看明细 →     │
└────────────────────────────────────────────────────────┘
```

**大卡结构（L）**：

```
┌ 表头：色条+图标+标题 │ Tab(总览/特保/非特保)居中 │ × ┐
├ 左栏 水球区 ─┬── 中栏 进度条区 ──┬── 右栏 列表区 ──┤
│             │ 正常结案  ● 126  │ 待关注单据      │
│   大水球    │ 进度条 ██████░░  │ ┌─────────────┐ │
│  中心 61.4% │ 到达超时  ●  36  │ │ 在途超时优先 │ │
│  结案完成率 │ 进度条 ████░░░░  │ │ 按超时降序   │ │
│             │ 在途超时  ●  40  │ │ 单号/门岗/   │ │
│ 图例胶囊×2  │ 进度条 █████░░░  │ │ 状态/时长    │ │
│ 图例胶囊×2  │ ────────────── │ 全部 N 条 →    │
│ (正常/未结案)│ 纳入统计 202 单  │ 点击查看完整明细│
│ 垂直居中    │ 垂直居中       │ flex:1 可滚动  │
│             │                │ 底部渐隐遮罩   │
└─────────────┴──────────────────┴─────────────────┘
```

**高度自适应规则**：
- 左栏（水球+图例）、中栏（进度条）：内容高度固定，**垂直居中**，不随卡片高度拉伸
- 右栏（待关注列表）：`flex: 1` 占满剩余高度，内容超出时 `overflow-y: auto` 滚动
- 列表底部有 **32px 渐隐遮罩**（透明→面板底色），防止滚动时内容在边界处生硬截断
- 卡片变高 → 列表区域变大，显示更多条目
- 卡片变矮 → 列表区域变小，出现滚动条

## 4. 数据字段

原型里的数字只是演示。实现时写对应的 `computeStats()` / `buildKpiProps` 字段名，禁止写死。

| UI 文案 | 字段 | 口径级别 | 说明 |
|---|---|---|---|
| 61.4%（主数字） | `closeRate` | 单 | = closedOrders / scopedOrders |
| 纳入统计 N 单 | `scopedOrders` | 单 | 分母 = 正常结案 + 到达超时 + 在途超时 |
| 正常结案 N 单 | `closedOrders` | 单 | 分子 = 已到达 && 未放行超时 |
| 到达超时 N 单 | `arrivedOvertime` | 单 | 已到达 && 放行超时 |
| 在途超时 N 单 | `inTransitOvertime` | 单 | 未到达 && 放行超时 |
| 在途未超 N 单 | `inTransitNormal` | 单 | 不计入分母，仅作说明 |
| 特保结案率 | `specialCloseRate` | 单 | Tab=特保时显示 |
| 非特保结案率 | `normalCloseRate` | 单 | Tab=非特保时显示 |
| 待关注单据列表 | `attentionOrders` | 单 | 在途超时 + 到达超时，按时长降序取前 N 条 |

> 口径定义见 CONTEXT.md §3「放行结案完成率」。

## 5. 交互

- **Tab 切换**（仅大卡）：总览 / 特保 / 非特保；切换时中栏水球百分比、颜色，左栏进度条数值同步变化；过渡 300ms
- **点击下钻**：卡片主体 / "查看明细 →" / "全部 N 条 →" / "点击查看完整明细 →" 均打开现有二级详情页（`detailKey: rate`）
- **拖拽缩放**：保持现有 gridstack 机制，尺寸跨越 S/M/L 断点时切换模板
- **水球动画**：波浪有轻微上下浮动效果（静态也可，优先保证性能）

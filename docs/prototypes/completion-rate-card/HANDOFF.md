## 1. 背景与目标

- **改什么卡**：`kpi_rate`（放行结案完成率），目前只有 S 小卡（水球图），补齐 M 中卡和 L 大卡形态

## 2. 设计 Token

与 `kpi-card-redesign/HANDOFF.md` §2 完全一致，复用现有语义色。本卡主色为绿色（正向达成率）。

| Token | 值（亮色） | 用途 |

| `--ok` / `--primary` | `#1ea672` 绿 | 主色（结案率、正常结案） |

## 3. 布局与分档

当前网格是 24 列 × 行高 48px（D-23）。KPI 换档条件见 ARCHITECTURE §4。

| 档 | 条件 | 卡内结构 |
|---|---|---|
| S | 小卡（默认 4×4） | 保持现状：标题 + 水球图 + 中心百分比，不动 |
| M | `h≥6` 或（`w≥10` 且 `h≥5`） | 左右分栏：左水球（约 120px） + 右三指标竖排（正常结案/到达超时/在途超时）；底部说明条 |
| L 宽屏 | `w≥12` 且 `h≥8`，卡片较宽 | 三栏布局：左栏水球+图例 / 中栏进度条三指标 / 右栏待关注单据列表 |
| L 方形 | `w≥12` 且 `h≥8`，卡片接近正方形 | 上两栏（水球 + 进度条）+ 下一栏横跨双列（在途超时列表 / 到达超时列表） |

当卡片宽度收窄到接近正方形时（约 700-900px），自动切换为方形布局：

```

│  红标 · N 单             │  橙标 · N 单             │

│  │ 单号 门岗  时长   │  │  │ 单号 门岗  时长    │   │
```

**布局逻辑**：
- **宽屏（>900px）**：三栏横排 — 水球（视觉焦点）→ 进度条（结构化数据）→ 列表（明细）
- **方形（700-900px）**：上半部分水球+进度条并排，下半部分横跨展示双列列表，充分利用横向空间
- **窄屏（<700px）**：单列堆叠，依次为水球 → 进度条 → 列表

## 4. 数据字段

原型里的数字只是演示。实现时写对应的 `computeStats()` / `buildKpiProps` 字段名，禁止写死。

| UI 文案 | 字段 | 口径级别 | 说明 |
|---|---|---|---|
| 61.4%（水球中心） | `closeRate` | 单 | = closedOrders / scopedOrders |
| 纳入统计 N 单 | `scopedOrders` | 单 | 分母 = 正常结案 + 到达超时 + 在途超时 |
| 正常结案 N 单 | `closedOrders` | 单 | 分子 = 已到达 && 未放行超时 |
| 到达超时 N 单 | `arrivedOvertime` | 单 | 已到达 && 放行超时 |
| 在途超时 N 单 | `inTransitOvertime` | 单 | 未到达 && 放行超时 |
| 在途未超 N 单 | `inTransitNormal` | 单 | 不计入分母，仅作说明 |
| 特保结案率 | `specialCloseRate` | 单 | Tab=特保时显示 |
| 非特保结案率 | `normalCloseRate` | 单 | Tab=非特保时显示 |
| 待关注单据列表 | `attentionOrders` | 单 | 在途超时 + 到达超时，在途超时优先，各自按时长降序 |

> 口径定义见 CONTEXT.md §3「放行结案完成率」。

## 5. 交互

- **Tab 切换**（仅大卡）：总览 / 特保 / 非特保，Tab 位于头部居中；切换时水球百分比/颜色、进度条数据、列表数据同步联动变化；过渡 300ms
- **点击下钻**：卡片主体 / "查看明细 →" / "全部 N 条 →" / "点击查看完整明细 →" / 列表行 均打开现有二级详情页（`detailKey: rate`）
- **拖拽缩放**：保持现有 gridstack 机制，尺寸跨越断点时切换模板；L 卡内部也随宽度在宽屏/方形/窄屏间自适应
- **水球动画**：波浪有轻微浮动效果（静态也可，优先保证性能）
- **列表排序**：在途超时优先展示（红色=重点关注），到达超时次之；两类各自按超时时长降序排列

🕓 单据追踪

该单记录明细

节点三态

  • 实心：已完成（有时间）
  • 空心橙：进行中（未完成，显示已等待）
  • 空心灰：未开始

状态色语义

  • 正常 / 已接收
  • 放行超时（含在途超时）
  • 接收超时 / 未接收
  • 特级安保单（WF9897）

耗时与卡点

  • 每段耗时 = 相邻节点时间差；未完成段显示已等待（now − 上一节点）。
  • 最长卡点：所有段取最大，整段标红并加「🔴 最长卡点」。
  • 段耗时 < 1 小时显示分钟，≥ 1 小时显示「x 小时 y 分」。

入口（4 处）

  • 主看板明细表单号列
  • 二级详情明细表单号列
  • 告警卡 / 未结案卡的单号
  • （后续）全局搜索

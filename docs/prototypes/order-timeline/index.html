抽屉尺寸

  • 追踪模式：min(95vw,920px)
    时间线是纵向列表，用 1180 右侧会留大片空白
  • 实现：给 #detailPanel 加 .trace-mode 切宽度，关闭时移除

严重度配色（本次调整）

  • 红：放行超时（含在途超时）—— 最严重
  • 黄：接收超时 / 超时未接收
  • 绿：正常 / 已接收
  • 紫：特级安保单（WF9897）

节点三态

  • 实心：已完成（按严重度着色）
  • 空心红：进行中且已超时（放行类）
  • 空心黄：进行中（接收类）
  • 空心灰：未开始

呈现形态（三选一）

  • A 纵向：列表式，节点再多也不挤；右侧留白
  • B 横向：流转图，铺满宽度、方向感强；节点 ≥6 需横向滚动
  • C 纵向+右栏：宽度用满，右栏 = 各段耗时排行 + 超时判定
  • 三者共用同一份数据与配色，只是排版不同；切换按钮在页面顶部

耗时与卡点

  • 段耗时 = 相邻节点时间差；未完成段显示已等待
  • 最长卡点整段标红 + 「🔴 最长卡点」
  • <1 小时显示分钟，≥1 小时显示「x 小时 y 分」

/* ============================================================
 * 视图插件规范（外部视图文件）
 * ============================================================
 * 放在本目录（views/）下，文件名任意，但需遵循以下格式。
 * 看板启动时会探测本目录下已注册的视图文件并合并到「视图」下拉。
 *
 * —— 如何创建一个视图插件文件 ——
 * 1. 在看板中排好卡片布局（编辑模式）
 * 2. 点击「💾 保存布局」→ 输入视图名称 → 保存
 * 3. 在浏览器控制台执行（把 视图名 换成你的名称）：
 *    saveViewPlugin("视图名")
 *    会自动生成 views/视图名.js 下载到本地，放入本目录即可
 *
 * —— 手动编写格式 ——
 * window.VIEW_PLUGIN = {
 *   id: "myview",              // 唯一 id（英文）
 *   name: "我的视图",           // 下拉显示名
 *   cols: 24,                  // 列制标记：写 24 表示已是 24 列坐标（推荐，见下）
 *   layout: [                   // 布局数组（gridstack x/y/w/h）
 *     { id: "kpi_overview", x: 0, y: 0, w: 4, h: 4 },
 *     ...
 *   ]
 * };
 *
 * —— cols 字段（重要）——
 * 看板网格是 24 列。带 cols: 24 的文件按原样加载；不带该字段的文件，
 * 若所有卡片右边界（x+w）≤ 12，会被当成 v5.5 的 12 列旧文件自动 ×2。
 * 所以：新写的视图请加 cols: 24，否则"只排左半边"的布局会被放大一倍。
 * （用看板「📤 导出视图文件」生成的插件已自动带 cols: 24。）
 * ============================================================ */
